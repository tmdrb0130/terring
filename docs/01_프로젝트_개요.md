# 01. 프로젝트 개요

## 문제 정의

- **입력**: 점수판과 스톤이 찍힌 사진 1장 (1050×1400)
- **출력**: 총점 + 판정 근거(각 스톤이 어느 칸에 닿아 몇 점인지)

### 게임 규칙
- 점수판: 3×3 칸 — 윗줄 4/2/4, 가운데줄 3/5/3, 아랫줄 2/1/2. 중앙에 5점 노란 원이 얹혀 있음
  - 실제 매트 구조(실측): 가운데 열은 위 2(빨강)/아래 1(파랑) 두 칸이고 그 경계 위에 5원이 있음.
    좌열 경계 y=0.325/0.661, 우열 y=0.326/0.661, 세로 경계 x=0.330/0.671, 원 중심 (0.495, 0.499) r=0.180
- 스톤: red/blue 각 팀 최대 3개, 총 0~6개
- 점수: 스톤이 **닿은 칸들 중 최고점**. 여러 칸에 걸치면 max. 점수판 밖이면 0점
- 장애물: 나무 기둥(점수 없음), 매트 아래쪽 파스텔 보드는 점수판이 아님(0점 처리)

## 데이터

`data/001~085 (08.16)/` — 85장 (001.jpg~085.jpg) + 사람 라벨 `terring_1_85.csv`

- 연속 촬영이 많아 **고유 장면은 약 40개** (같은 배치를 여러 각도로 촬영)
- 분포 편중: 보드 위 스톤 1개짜리 31장 vs 6개짜리 2장
- 알려진 결함: 프레임에 잘린 스톤 4장(003/015/080/082, 전부 0점), 조명 반사로 색이 날아간 스톤 다수

### 라벨 형식 (terring_1_85.csv)

| 컬럼 | 의미 |
|---|---|
| image | 파일명 |
| sN_color | 스톤 N의 색 (red/blue, 없으면 빈칸) |
| sN_cells | 닿은 칸 숫자를 이어붙임 (예: `2345` = 2,3,4,5칸에 걸침). 보드 밖 = `0` |
| sN_score | max(cells) — 수식/스크립트로 자동 계산 |
| num_stones / total_score | 자동 계산 |

**2026-08-16 라벨 정정 이력**: 사용자가 검토 카드 14건을 판정하여 11개 셀 수정
(001~003: 345→2345, 006~010: 1235→35, 018/020/021: 12→0, 038: 4→1).
수정 전 백업: `terring_1_85.csv.bak`

## 평가 지표 (엄격한 순)

1. **스톤 단위**: 각 스톤의 (색, 닿은 칸 집합)이 라벨과 일치한 비율 — 분모는 전체 스톤 수
2. **총점 일치**: 이미지의 최종 점수가 일치한 비율 — 분모는 이미지 수
3. **완전 일치**: 스톤 개수 + 모든 스톤의 색·닿은 칸이 전부 일치 — 가장 엄격, 최종 목표 지표
