## 1. 데이터 정리·라벨링 체계
- 카카오톡 파일명 80장을 촬영 시간순으로 001~085.jpg로 정리 (기존 001~005와 합쳐 85장)
- 라벨 스키마 설계: 스톤별 (색, 닿은 칸들) 상세 라벨. 구글시트 수식 포함 CSV 생성
  - 칸 입력을 `2/3` → `23` (숫자 이어붙임)으로 변경: 날짜 자동변환 문제 회피
- 사용자가 85장 수작업 라벨링 완료 → 검증 결과 정합성 오류 0건

## 2. 데이터 분할
- 처음엔 총점 구간 층화 7:3 → 사용자 피드백으로 **난이도 층화**(보드 위 스톤 수 × 겹침 정도)로 재분할
- train 58 / test 27. 8개 난이도 층 각각에서 7:3 추출. 양쪽 분포 균형 확인 (스톤 평균 2.47 vs 2.56)

## 3. model_001: 총점 회귀 CNN
- v1(ResNet18, 320px): test MAE 1.22, 정확 30% — 단 test를 얼리스탑에 사용한 leakage 있음
- v2(train/val 분리, 강화 증강): 정확 48%, leakage 제거
- v3(ResNet34, 384px, 5-fold 앙상블, 무한 on-the-fly 증강, TTA): **정확 52%, MAE 0.78**
- 결론: 목표 90%에 크게 미달. 위치를 명시적으로 다루지 않는 구조의 한계 확인 → 방향 전환

## 4. model_002: CV 파이프라인 구축 (시행착오 포함)
1. 보드 검출: 색 마스크 + 컨투어 → 코너. 라인 피팅으로 정밀화
2. 캘리브레이션 실패→해결: 개별 이미지에서 경계 검출은 스톤 가림에 취약
   → **85장 프로파일 합산 후 일괄 실측**으로 전환. 검은 선은 임계값 대신 V(밝기) 최저점으로
   → 좌우 독립 측정값이 일치(0.324/0.326)해 신뢰도 검증됨
3. 스톤 검출 시행착오:
   - 꼭지(분홍) 단독 → 조명에 날아간 꼭지(S=20, V=254 백색화) 놓침
   - 꼭지 임계 완화 → 빨간 칸이 대량 오검출 (S 상한이 핵심임을 발견: 꼭지 S40-90 vs 칸 S120+)
   - Hough 원 추가 + 나무 링 검증 → 링 위치가 원 바깥이 아니라 **안쪽(0.75-1.05r)**임을 발견
   - 어두운 기둥 단면 오검출(H5 S116 V54, red 투표 0.82) → 빨강만 밝기 조건 추가로 해결
   - LED 발광 꼭지 스톤 → "강한 색+측면 그림자" 경로 추가
   - 프레임 잘림 스톤 → 경계 블롭 검출 시도했으나 배경 오검출 폭발로 **롤백** (알려진 한계로 남김)
4. 접촉점 보정: 이미지 아래방향 상수 → 워프 공간 → **스톤별 실루엣 최하단점 기반**으로 진화.
   최종 그리드서치 결과 alpha=0 (꼭지 중심이 이미 최적)
5. eval_cv의 circle_r 누적 표류 버그 수정 (실측 기준값 circle_r_cal 분리)
- 결과: 완전 64%→73% (라벨 정리 전)

## 5. 라벨 분쟁 정리 (정답지 청소)
- 자동판정 vs 사람 라벨 불일치를 전수 분류 → 검토 카드 14건 생성 (review_sheet.py)
  - 카드: [원본 확대 | 정면 보정+칸 경계+접촉원] + "자동 vs 라벨, 어느 쪽?"
- **사용자 판정: 라벨 수정 7건 / 자동(기하) 오류 7건** → fix_labels.py로 11개 셀 수정 (백업 보존)
- 효과: model_002가 완전 73→**84%**, 총점 82→**88%**, 스톤 94→**97%** (85장 전체)
- 교훈: 90% 달성의 절반은 모델이 아니라 정답지 품질 문제였음

## 6. model_003: 탐지 CNN
- gen_labels.py: CV로 85장 좌표 pseudo-label 자동 생성 (수작업 0시간)
- v1 첫 학습 실패: 히트맵이 전부 0으로 붕괴 (희소 타깃 + MSE의 전형적 실패)
  → **CenterNet식 focal loss + 출력 bias -2.19 초기화**로 해결
- v1 결과: 스톤 88% / 총점 74% / 완전 59%. 중복 피크로 +3~5점 오류 2건
- v2 (라벨 정리 후 + 기술 개선 ④⑤⑥⑧):
  - 해상도 384×512→576×768, 서브픽셀 오프셋 헤드, 코너 히트맵(회귀 폴백),
    색당 최대 3개 제약 + 지름 기반 NMS, 5-fold 앙상블 + 좌우반전 TTA, 임계값 스윕
  - fold 0이 2에폭 만에 val 완전 12/12 달성
  - **최종: 스톤 95% / 총점 81% / 완전 81% / MAE 0.19 — 스승(CV)과 동급**

## 오늘의 핵심 교훈
1. 총점만 학습하는 CNN은 한계 명확 (52%). **위치 명시 탐지 + 기하 계산** 구조가 정답
2. 자동 판정과 사람 라벨의 불일치는 "모델 오류"가 아니라 절반이 **라벨 문제**였음
   → 불일치 검토 루프(자동 라벨 → 사람은 분쟁만 판정)가 라벨 품질 관리의 핵심 자산
3. 희소 히트맵엔 MSE 금지, focal loss 필수
4. 소량 데이터에서 CNN 좌표 정밀도는 해상도 + 서브픽셀 오프셋이 결정적
